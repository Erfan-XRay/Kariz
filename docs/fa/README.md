# مستندات فارسی

[English](../README.md) · **فارسی**

همهٔ مستندات کاریز به فارسی هم هست. نام تنظیم‌ها، دستورها و مقدارها همان انگلیسی می‌ماند، چون همان‌هاست که در کانفیگ و ترمینال می‌نویسید. همین صفحه‌ها با جستجو، نمودارهای متحرک و دموی زندهٔ پنل در وب‌سایت هستند: <https://erfan-xray.github.io/Kariz/fa/>
