# مستندات فارسی

[English](../README.md) · **فارسی**

راهنماهایی که برای راه انداختن و اداره کردن کاریز لازم دارید به فارسی هم هستند. صفحه‌های مرجع (کانفیگ، ترنسپورت‌ها، سند status و ...) انگلیسی می‌مانند، چون واژه‌هایشان همان است که در کانفیگ می‌نویسید.

| صفحه | دربارهٔ |
|---|---|
| [شروع کار](getting-started.md) | نصب، token، دو کانفیگ، اجرا |
| [اسکریپت مدیر](manager.md) | نصب و اداره کردن تانل‌ها با `kariz-manager` |
| [پنل وب](panel.md) | پنل، ویزارد تانل، نظارت، پشتیبان، به‌روزرسانی |
| [شبکه‌های خصوصی (GRE)](networks.md) | آدرس خصوصی بین سرورها، هرگز تکراری |
| [امنیت](security.md) | چه چیزی از ترافیک محافظت می‌کند و چه چیزی را می‌شود دید |
| [عیب‌یابی](troubleshooting.md) | پیام‌ها، علت‌ها و راه‌حل‌ها |
